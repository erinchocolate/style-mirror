# Observations

Cross-session notes about the user's evolving voice — the layer above individual session evidence. LEARN drops a line here when a signal is surprising or spans scenarios; DISTILL adds a short weekly reflection.

Keep entries to 2–3 sentences. Record only things with reuse value; if nothing's worth noting, write nothing.

## Priority key

- 🔴 **Red** — a strong, cross-scenario voice trait or hard constraint (high reuse value; likely belongs in the profile as a high-confidence rule).
- 🟡 **Yellow** — a notable pattern, conflict, or shift worth watching (e.g. a rule went contested, diff_size stopped shrinking).
- 🟢 **Green** — routine note (a tentative rule appeared, a session logged).
